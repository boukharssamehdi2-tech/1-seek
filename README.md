# 1-Seek — Snake Hunt 🐍

Jeu interactif développé en **HTML, CSS et JavaScript** (Canvas 2D), jouable directement dans un navigateur.

## Jouer

Site : https://boukharssamehdi2-tech.github.io/1-seek/ (après activation de GitHub Pages).

Déplacez le curseur dans l'arène pour diriger le serpent et attraper les souris. Chaque souris mangée augmente le score et la longueur du serpent.

## Fonctionnalités

- Arène futuriste sombre avec grille hexagonale et néons
- Plusieurs souris qui fuient le serpent et se fatiguent
- Score, longueur et chronomètre
- Réglages : nombre de souris, vitesses, agilité, longueur initiale, rayon de fuite
- Pause, recommencer et nouvelle vague de souris

## Lancer localement

Ouvrir `index.html` dans un navigateur. Aucune installation ni dépendance n'est nécessaire.

## Hébergement GitHub Pages

Dans le dépôt : **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.
